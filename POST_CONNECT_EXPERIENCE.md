# Cin7 Core Connector — что видит и чем управляет пользователь после подключения

## 1. Целевой пользователь
Операционный менеджер/владелец бизнеса с физическим товаром (опт, мелкое производство,
мультиканальная розница), использующий Cin7 Core как систему управления запасами (IMS).

## 2. Момент истины после подключения
Сразу после `connect_cin7_core` — сводка по остаткам: что заканчивается на складе,
сколько заказов на производство/закупку сейчас в процессе.

## 3. Что пользователь видит
- Товары (SKU) с остатками по каждому складу — `list_products`, `get_stock_levels`.
- Заказы на продажу (Sale Orders) со статусом фулфилмента — `list_sale_orders`.
- Заказы на закупку (Purchase Orders) с ожидаемой датой поставки — `list_purchase_orders`.
- Производственные заказы (Production Orders), если есть сборка из компонентов —
  `list_production_orders`.
- Отчёт по товарам, которых мало в наличии — `get_low_stock_report`.
- Поставщиков и клиентов (B2B) — `list_suppliers`, `list_customers`.
- Ценовые листы (разные цены для разных каналов/клиентов) — `list_price_lists`.

## 4. Чем пользователь может управлять
- Создавать/изменять заказ на продажу, включая мультисклад — `create_sale_order`,
  `update_sale_order`.
- Создавать заказ на закупку у поставщика — `create_purchase_order`.
- Регистрировать поступление товара на склад (получение по PO) — `receive_stock`.
- Запускать производственный заказ (собрать готовое изделие из компонентов) —
  `create_production_order`.
- Делать инвентаризационную корректировку остатков — `adjust_stock`.
- Перемещать товар между складами — `create_stock_transfer`.

## 5. "Вау"-момент для демо потенциальному клиенту
"Смотри — говорю Webbee: 'что у меня заканчивается на всех складах прямо сейчас?'. Она
находит через `get_low_stock_report` конкретные SKU, а я прошу создать заказ на закупку
недостающего у нужного поставщика — `create_purchase_order` делает это сразу."

## 6. Что делает это "заточенным под него"
`list_price_lists` работает с РЕАЛЬНЫМИ ценовыми политиками именно этого бизнеса (опт vs
розница, канал А vs канал Б) — Webbee не предлагает одну цену на всё.
