# Cin7 Core Connector — идеальный первый запуск

Источник: `ONBOARDING_FIRST_LAUNCH_STANDARD.md`. Целевой пользователь: операционный
менеджер/владелец бизнеса с физическим товаром на Cin7 Core (IMS).

## 1. Credential type
Account ID (GUID) + Application key.

## 2. Идеальный флоу
1. **Первое открытие** — `Empty` со ссылкой "Settings > Integrations & API > API keys"
   + объяснение, что Account ID — это GUID, не читаемое имя компании (частая путаница).
2. **Форма** — account_id + application_key, оба с лейблами и явным форматом (GUID
   пример в placeholder).
3. **После успеха** — сводка остатков (что заканчивается) + заказы на
   производство/закупку в процессе — сразу.
4. **Low-stock alert emphasis** — идеально: если есть товары с нулевым/отрицательным
   остатком — это должно быть ПЕРВЫМ, что видно (не просто строка в таблице), т.к. это
   прямая потеря продаж.
5. **Ошибка "invalid account/application key pair"** — конкретное сообщение, что
   ключи должны быть из одного и того же Cin7 Core аккаунта.
